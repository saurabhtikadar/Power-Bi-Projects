# HR Analysis Dashboard with Navigation Menu

This repository contains a Power BI report file, **HR Analysis with Navigation Menu.pbix**, designed to provide comprehensive insights into HR data with a user-friendly navigation experience.

## About the Project

This dashboard was developed as part of an internship project at **Elevate Labs**. It demonstrates proficiency in Power BI, data visualization, and dashboard design tailored to HR analytics.

## Key Features

- **Interactive Navigation Menu**: Easily switch between pages and sections for a seamless user experience.
- **HR Metrics and KPIs**: Includes metrics like Total employee Due for promotion, Service year, Overtime Employees and more.
- **Dynamic Visuals**: Utilizes interactive charts, graphs, and Table for deeper data exploration.
- **Customizable Filters**: Filter data by department, time frame, and other key dimensions.
- **Data-Driven Insights**: Enables decision-makers to analyze workforce performance and trends.

## Requirements

To open, explore, and customize this report, the following tools and skills are required:

- **Power BI Desktop**: Install the latest version to work with the `.pbix` file.
- **Power Query**: Used for data transformation and preparation.
- **DAX (Data Analysis Expressions)**: Utilized for creating calculated measures, columns, and advanced data modeling.

## Dataset

The report is based on two CSV files that provide the data for analysis:

1. **HR Analytics Data.csv**: Contains detailed employee information such as:
   - Employee ID
   - Department
   - Job Role
   - Demographics (e.g., age, gender)
   - Service Year
   - More

2. **HR Employee Data.csv**: Includes satisfaction and engagement metrics:
   - Employee ID
   - Employee Name
